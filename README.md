# Проект анализа вакансий из HeadHunter

## Описание проекта

Этот проект направлен на создание модели машинного обучения, которая будет рекомендовать вакансии клиентам агентства, претендующим на позицию Data Scientist. Проект включает анализ данных о вакансиях, работодателях, регионах и сферах деятельности, а также построение модели рекомендаций на основе этих данных.

## Структура данных

Проект использует схему данных `public` из базы данных `project_sql`, которая включает следующие таблицы:

- **vacancies**: данные по вакансиям
  - `id`: ID вакансии
  - `name`: Название вакансии
  - `key_skills`: Ключевые навыки
  - `schedule`: Тип рабочего графика
  - `experience`: Требования к опыту
  - `employment`: Тип трудоустройства
  - `salary_from`: Нижняя граница зарплатной вилки
  - `salary_to`: Верхняя граница зарплатной вилки
  - `area_id`: ID региона вакансии
  - `employer_id`: ID работодателя

- **areas**: справочник регионов
  - `id`: Идентификатор города
  - `name`: Название города

- **employers**: справочник работодателей
  - `id`: Номер работодателя
  - `name`: Название работодателя
  - `area`: Регион регистрации

- **industries**: справочник сфер деятельности работодателей
  - `id`: ID сферы деятельности
  - `name`: Название сферы деятельности

- **employers_industries**: связь между работодателями и сферами их деятельности
  - `employer_id`: ID работодателя
  - `industry_id`: ID сферы деятельности

## Анализ данных

### Предварительный анализ

- В базе данных содержится 49197 вакансий, 23501 работодателей, 1362 регионов и 294 сфер деятельности.
- Таблицы взаимосвязаны между собой по полям `id`, что позволяет провести детальный анализ данных.

### Детальный анализ вакансий

- Спрос на трудовые ресурсы сосредоточен в крупных городах.
- 49% вакансий содержат информацию о зарплате, со средними значениями от 70 до 110 тысяч рублей.
- Большинство вакансий включает полную занятость с полным рабочим днем (72%) или удаленным графиком (16%).
- Наиболее востребованы специалисты с опытом работы от 1 до 3 лет (53%) и от 3 до 6 лет (29%).

### Анализ работодателей

- Больше всего вакансий размещают компании из ИТ, телекоммуникационного, финансового и нефтегазового секторов.
- 36% работодателей не указывают сферу деятельности.
- Наибольшая концентрация вакансий наблюдается в городах с населением более 1 миллиона человек (48,5%).

### Анализ вакансий Data Scientist

- Вакансии в сфере Data Science составляют 3,6% от общего количества вакансий.
- Только 2,88% вакансий подходят для начинающих специалистов.
- Наиболее востребованные навыки включают Python (20,16%) и SQL/Postgres (12,93%).
- Средняя зарплата варьируется в зависимости от опыта: от 74643 рублей для начинающих до 243115 рублей для специалистов с опытом от 3 до 6 лет.

## Использование

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/st-pavel/Job-Vacancy-Analysis-Project-from-HeadHunter.git
   ```
2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите Jupyter Notebook и откройте файл `project_2_notebook.ipynb` для выполнения анализа и построения модели.

## Заключение

Этот проект предоставляет детальный анализ рынка труда для Data Scientist и помогает лучше понять текущие тенденции и требования работодателей. Модель рекомендаций, построенная на основе этих данных, может быть полезна для агентств по трудоустройству и соискателей.
